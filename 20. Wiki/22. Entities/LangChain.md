# LangChain

## Overview

LangChain 홈페이지는 LangChain을 여러 모델 제공자와 함께 에이전트를 빠르게 구축하기 위한 오픈소스 프레임워크로 제시한다. 같은 제품군에서 [[LangGraph]]는 더 낮은 수준의 제어, [[Deep Agents]]는 개방형 장기 작업에 초점을 둔다.

## 과제 활용

	- 모델 호출, 도구 연결, 기본 에이전트 패턴을 빠르게 구성하는 시작점으로 검토한다.
	- 복잡한 승인·재시도·상태 분기가 핵심이면 [[LangGraph]]가 더 직접적인 후보가 된다.
	- 실제 선택 전 강의 실습과 공식 문서에서 API와 제약을 확인한다.

> [!warning] Evidence Boundary
>	현재 설명은 제품 홈페이지의 포지셔닝 문구에 근거한다. 성능, 안정성, 학습비용을 비교 검증한 결과가 아니다.
