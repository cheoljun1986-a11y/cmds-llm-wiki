# Deep Agents

## Overview

LangChain 홈페이지는 Deep Agents를 개방형이고 장기 실행되는 작업을 수행하는 지능형 에이전트용 프레임워크로 소개한다.

## 과제 적합성

현재 현업과제는 정해진 데이터 검증·모델 실행·승인 절차가 중요하므로, 개방형 자율성보다 [[LangGraph]]의 명시적 제어가 더 직접적인 후보다. Deep Agents는 탐색적 조사나 장기 연구 에이전트가 과제 범위에 포함될 때 비교한다.

> [!warning] Evidence Boundary
>	홈페이지의 한 줄 포지셔닝만 확인한 상태다. 구체 기능과 LangGraph 대비 장단점은 검증하지 않았다.
