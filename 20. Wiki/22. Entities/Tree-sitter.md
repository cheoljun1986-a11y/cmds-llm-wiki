# Tree-sitter

## Role in This Cluster

Tree-sitter는 [[Graphify]]가 코드에서 AST, 호출 그래프, 주석을 추출하는 정적 분석 구성요소로 소개된다. 이 역할은 문서·다이어그램의 모델 기반 해석과 구분되며 [[Static-Semantic Hybrid Extraction]]의 결정론적 측면을 담당한다.

## Verification Boundary

현재 페이지는 Graphify 홈페이지가 설명한 사용 방식만 기록한다. Tree-sitter 자체의 언어 지원 범위, 증분 파싱 특성, Graphify 내부 추출 정확도는 공식 Tree-sitter 문서와 Graphify 소스 코드를 별도로 검증해야 한다.
