# Graph Neural Network(GNN) 핵심 정리

## 한 줄 요약

**GNN은 각 노드가 주변 이웃의 정보를 전달받고 집계하면서, 그래프의 구조와 노드 특성을 함께 학습하는 신경망이다.**

## 왜 GNN이 필요한가?

CNN과 RNN은 이미지의 격자 구조나 문장의 순서처럼 규칙적인 구조를 처리하는 데 적합하다.

하지만 다음과 같은 데이터는 연결 구조가 일정하지 않은 **그래프 형태**로 표현된다.

- 소셜 네트워크
- 인용 네트워크
- 지식 그래프
- 단백질 상호작용 네트워크
- 분자 구조
- 도로망
- 사용자–상품 상호작용

그래프 데이터에서는 각 데이터가 독립적으로 존재하지 않고, **노드 사이의 연결 관계 자체가 중요한 정보**가 된다.

그래프는 보통 다음 두 행렬로 표현한다.

### 노드 특성 행렬 XXX

X∈RN×CX \in \mathbb{R}^{N \times C}X∈RN×C

- NNN: 노드 개수
- CCC: 각 노드가 가진 특성 개수
- XiX_iXi: 노드 iii의 특성 벡터

### 인접 행렬 AAA

A∈RN×NA \in \mathbb{R}^{N \times N}A∈RN×N

노드 iii와 jjj가 연결되어 있으면 Aij=1A_{ij}=1Aij=1, 연결되어 있지 않으면 000으로 표현한다.

### 노드 분류 결과 YYY

Y∈RN×FY \in \mathbb{R}^{N \times F}Y∈RN×F

YijY_{ij}Yij는 노드 iii가 클래스 jjj에 속할 확률을 의미한다.

# Transductive Learning과 Inductive Learning

## Transductive Learning

학습할 때 테스트 노드를 포함한 **전체 그래프 구조와 노드 특성**을 볼 수 있다.

다만 테스트 노드의 정답 레이블은 사용하지 않는다.

예시:

- 하나의 논문 인용 네트워크에서 일부 논문의 분야만 알고 있는 경우
- 나머지 논문의 분야를 예측하는 문제

## Inductive Learning

학습할 때 존재하지 않았던 새로운 노드 또는 새로운 그래프에도 적용해야 한다.

예시:

- 신규 사용자가 추가된 추천 시스템
- 학습에 포함되지 않은 새로운 분자 그래프
- 서로 완전히 다른 단백질 네트워크

새로운 그래프 구조에도 일반화해야 하므로 Transductive Learning보다 어려운 문제다.

# GNN의 핵심 원리: Message Passing

GNN의 기본 아이디어는 다음과 같다.

> 각 노드는 이웃 노드로부터 메시지를 받고, 메시지를 집계하여 자신의 표현을 업데이트한다.

노드 vvv의 kkk번째 계층 표현은 일반적으로 다음 과정으로 계산된다.

1. 이웃 노드의 표현을 수집한다.
2. 평균, 합, 최대값 등의 방식으로 집계한다.
3. 자신의 기존 표현과 이웃 정보를 결합한다.
4. 신경망과 활성화 함수를 적용한다.

GNN 계층이 깊어질수록 더 멀리 떨어진 노드의 정보가 전달된다.

- 1개 계층: 1-hop 이웃 정보
- 2개 계층: 2-hop 이웃 정보
- kkk개 계층: kkk-hop 이웃 정보

# GCN: Graph Convolutional Network

GCN은 주변 노드의 정보를 **정규화된 가중 평균 방식으로 집계**하는 대표적인 GNN 모델이다.

## Self-loop 추가

자신의 정보도 집계에 포함하기 위해 인접 행렬에 단위 행렬을 더한다.

A~=A+I\tilde{A}=A+IA~=A+I

## 정규화된 인접 행렬

A^=D~−12A~D~−12\hat{A} = \tilde{D}^{-\frac{1}{2}} \tilde{A} \tilde{D}^{-\frac{1}{2}}A^=D~−21A~D~−21

여기서 D~\tilde{D}D~는 각 노드의 연결 개수를 나타내는 차수 행렬이다.

## GCN 계층

H(l+1)=σ(A^H(l)W(l))H^{(l+1)} = \sigma \left( \hat{A}H^{(l)}W^{(l)} \right)H(l+1)=σ(A^H(l)W(l))

- H(l)H^{(l)}H(l): 현재 계층의 노드 표현
- W(l)W^{(l)}W(l): 학습할 가중치
- A^\hat{A}A^: 정규화된 인접 행렬
- σ\sigmaσ: 활성화 함수

## 직관적 의미

A^H\hat{A}HA^H

는 각 노드가 자신과 이웃 노드의 정보를 적절한 비율로 섞는 과정이다.

그 후,

A^HW\hat{A}HWA^HW

를 통해 이웃 정보가 반영된 새로운 노드 임베딩을 생성한다.

## 장점

- 모든 노드에 동일한 가중치를 공유한다.
- 노드 순서가 바뀌어도 결과가 유지된다.
- 계산 복잡도가 간선 수에 비례한다.
- Transductive와 제한적인 Inductive 환경에 사용할 수 있다.

## 단점

- 깊은 모델에서는 Oversmoothing이 발생한다.
- 간선 특성을 직접 반영하기 어렵다.
- 일반적으로 많은 계층을 쌓기 어렵다.

# Oversmoothing Problem

GNN 계층을 깊게 쌓으면 각 노드는 점점 더 넓은 범위의 이웃 정보를 전달받는다.

계층이 지나치게 깊어지면 서로 다른 노드의 표현이 계속 평균화되어, 결국 모든 노드의 임베딩이 비슷해질 수 있다.

이를 **Oversmoothing**이라고 한다.

## 결과

- 서로 다른 노드를 구분하기 어려워진다.
- 노드 분류 성능이 떨어질 수 있다.
- GCN과 GraphSAGE는 일반적으로 2~3개 계층 정도가 효과적이다.

## 강의에서 제시한 대응 방법

- Self-connection 추가
- RNN 구조 활용
- Residual connection 사용
- 계층 간 파라미터 공유

---

# GraphSAGE

GraphSAGE는 단순히 이웃의 평균만 계산하지 않고, 다양한 집계 함수로 이웃 정보를 결합한다.

## 핵심 아이디어

1. 이웃 노드의 표현을 집계한다.
2. 자신의 표현과 이웃 표현을 연결한다.
3. 새로운 노드 임베딩을 생성한다.


GCN과 달리 **자신의 임베딩과 이웃 임베딩을 명시적으로 구분하여 결합**한다.

## 집계 방법

### Mean Aggregator

이웃 노드 표현의 평균을 사용한다.

AGG=1∣N(v)∣∑u∈N(v)huAGG = \frac{1}{|N(v)|} \sum_{u\in N(v)}h_uAGG=∣N(v)∣1u∈N(v)∑hu

### Pooling Aggregator

각 이웃 표현을 신경망으로 변환한 후, element-wise max 또는 mean을 사용한다.

### LSTM Aggregator

이웃 노드의 표현을 임의의 순서로 배치하고 LSTM으로 집계한다.

## 특징

- 다양한 이웃 집계 함수를 사용할 수 있다.
- 새로운 노드에도 임베딩을 생성할 수 있다.
- 대규모 그래프에서는 전체 이웃 대신 일부 이웃을 샘플링할 수 있다.

# GAT: Graph Attention Network

GCN은 이웃 노드의 정보를 차수에 따라 정규화하지만, GAT는 **각 이웃의 중요도를 Attention으로 학습**한다.

## 핵심 아이디어

모든 이웃이 같은 중요도를 가진다고 가정하지 않는다.

노드 iii가 이웃 jjj의 정보를 얼마나 참고할지 Attention coefficient αij\alpha_{ij}αij로 계산한다.

hi′=σ(∑j∈N(i)αijWhj)h'_i = \sigma \left( \sum_{j\in N(i)} \alpha_{ij}Wh_j \right)hi′=σj∈N(i)∑αijWhj

## Multi-head Attention

여러 개의 Attention head를 사용해 서로 다른 관점에서 이웃 정보를 집계한다.

각 head의 결과는 다음 방식으로 결합할 수 있다.

- Concatenation
- Average

## 장점

- 중요한 이웃에 더 높은 가중치를 줄 수 있다.
- Inductive 환경에서 효과적으로 사용할 수 있다.
- GCN보다 유연한 이웃 집계가 가능하다.

## 단점

- GCN보다 계산 속도가 느리다.
- 최적화가 어려울 수 있다.
- 간선 임베딩을 직접 사용하는 GNN보다 표현력이 제한될 수 있다.

---

# Gated GNN

Gated GNN은 GNN을 깊게 만들기 위해 RNN의 아이디어를 적용한 모델이다.

## 기존 깊은 GNN의 문제

- 계층 수 증가에 따른 파라미터 증가
- Oversmoothing
- Gradient vanishing 또는 exploding
- 과적합

## 핵심 아이디어 1: 계층 간 파라미터 공유

각 계층마다 새로운 신경망을 사용하는 대신, 동일한 가중치를 반복해서 사용한다.

## 핵심 아이디어 2: GRU 기반 상태 업데이트

먼저 이웃 노드의 메시지를 집계한다.

mvk=W∑u∈N(v)huk−1m_v^k = W \sum_{u\in N(v)} h_u^{k-1}mvk=Wu∈N(v)∑huk−1

그 후 기존 노드 상태와 이웃 메시지를 GRU에 입력한다.

hvk=GRU(hvk−1,mvk)h_v^k = GRU(h_v^{k-1},m_v^k)hvk=GRU(hvk−1,mvk)

새로운 노드 상태는 다음 두 정보를 모두 반영한다.

- 이전 단계의 노드 상태
- 현재 단계에서 받은 이웃 메시지

## 장점

- 20개 이상의 계층을 구성할 수 있다.
- 멀리 떨어진 노드의 정보를 전달할 수 있다.
- 그래프의 전역 구조를 노드 표현에 반영할 수 있다.

예시:

## Graph Classification

예시:

P(Aij=1)=σ(ziTzj)P(A_{ij}=1) = \sigma(z_i^Tz_j)P(Aij=1)=σ(ziTzj)

# 반지도학습 기반 노드 분류

그래프의 일부 노드에만 레이블이 있는 경우에도 GNN을 사용할 수 있다.

학습 과정에서는 레이블이 있는 노드에 대해서만 손실을 계산하지만, 메시지 전달 과정에서는 레이블이 없는 노드의 특성과 연결 정보도 활용한다.

대표적인 예가 논문 인용 네트워크 분류다.

- 노드: 논문
- 간선: 논문 사이의 인용 관계
- 노드 특성: 논문 단어 정보
- 예측 대상: 논문의 연구 분야

# 추천 시스템에서의 GNN

추천 시스템은 사용자와 상품의 상호작용을 이분 그래프로 표현할 수 있다.

- 사용자 노드
- 상품 노드
- 클릭, 구매, 저장 등의 상호작용 간선

기존 추천 시스템은 다음 정보를 따로 처리하는 경우가 많다.

- 사용자와 상품의 콘텐츠 정보
- 사용자–상품 상호작용 구조

GNN은 두 정보를 하나의 모델에서 함께 사용할 수 있다.

# Pinterest의 RW-GCN 사례

Pinterest는 Pin과 Board의 관계를 그래프로 표현하고, 관련 Pin을 추천하는 데 GNN을 활용했다.

## RW-GCN

RW-GCN은 Random-Walk GCN으로, GraphSAGE를 확장한 모델이다.

## 학습 과정

1. 사용자 로그에서 연속으로 클릭된 Pin 쌍을 수집한다.
2. 함께 클릭된 Pin의 임베딩이 가까워지도록 학습한다.
3. 모든 Pin의 임베딩을 미리 생성한다.
4. 실시간으로 최근접 이웃 검색을 수행해 관련 Pin을 추천한다.

## Max-margin Loss

Positive pair의 유사도는 높이고, Negative pair의 유사도는 낮추도록 학습한다.

## 대규모 그래프 처리 방법

### Neighborhood Subsampling

모든 이웃을 사용하지 않고 일부 이웃만 선택한다.

Random Walk를 이용하여 Personalized PageRank 점수를 근사하고, 점수가 높은 Top-K 노드를 이웃으로 선택한다.

### Producer–Consumer Pipeline

CPU와 GPU의 역할을 분리한다.

**CPU**

- Pin 배치 선택
- Random Walk 수행
- 계산 그래프 생성

**GPU**

- 다계층 이웃 집계
- 손실 계산
- 역전파

### Curriculum Learning

초기에는 쉽게 구분되는 Negative sample을 사용하고, 학습이 진행될수록 더 어려운 Negative sample을 추가한다.

# 핵심 정리

1. 그래프 데이터에서는 개별 노드의 특성과 노드 사이의 연결 구조를 함께 고려해야 한다.
2. GNN은 이웃 노드의 메시지를 집계하여 노드 표현을 반복적으로 업데이트한다.
3. GCN은 정규화된 인접 행렬을 이용해 이웃 정보를 평균적으로 결합한다.
4. GraphSAGE는 다양한 집계 함수와 이웃 샘플링을 사용한다.
5. GAT는 Attention을 통해 이웃마다 다른 중요도를 학습한다.
6. Gated GNN은 GRU와 파라미터 공유를 사용해 깊은 GNN을 구성한다.
7. GNN이 지나치게 깊어지면 노드 표현이 유사해지는 Oversmoothing이 발생할 수 있다.
8. GNN은 노드 분류, 그래프 분류, 링크 예측, 추천 시스템 등에 활용할 수 있다.
9. 대규모 그래프에서는 이웃 샘플링과 CPU–GPU 파이프라인 설계가 중요하다.

## 최종 이해

> GNN은 연결된 데이터를 독립적인 샘플로 보지 않고, 주변 노드와의 관계를 이용해 각 노드의 의미를 학습하는 모델이다. 모델별 차이는 주로 **어떤 이웃을 선택하고, 이웃의 정보를 어떤 방식으로 집계하며, 기존 노드 정보와 어떻게 결합하는가**에 있다.
